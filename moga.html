Formulasi Masalah Matematis & Operator Genetika NSGA-II

Struktur Kromosom Individu (X)

X = [ T_set, PWM_Z1, PWM_Z2, FanSpeed ]

Gen bernilai riil dengan batas domain: Tset ∈ [20, 28]°C, PWM ∈ [0, 255], Fan ∈ [1, 3].

Fast Non-Dominated Sorting

p ≺ q ⇔ (f₁(p) ≤ f₁(q) ∧ f₂(p) ≤ f₂(q))

Mengklarifikasi populasi ke dalam rank non-dominasi (Rank 1, Rank 2, ...) untuk menjaga elitisme.

Metrik Crowding Distance (I_distance)

I_dist = ∑ (f_m(i+1) - f_m(i-1)) / (f_m^max - f_m^min)

Menghitung kepadatan solusi sekitar untuk memprioritaskan individu di area jarang agar front tidak mengelompok.
