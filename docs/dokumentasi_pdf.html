BEMS Living Lab FT UNS — Dokumentasi Teknis Optimasi Bab 1: Pendahuluan

1. Pendahuluan & Latar Belakang Masalah

Fasilitas Living Lab Smart Office Departemen Teknik Elektro FT UNS dirancang sebagai ruang kerja cerdas seluas 72 m² (tinggi 3.2 m) yang mengintegrasikan submetering energi digital (PZEM-004T), jaringan sensor IoT nirkabel (SHT31 multi-workstation), stasiun cuaca outdoor (RS485 Modbus), dan aktuator otomasi (IR Blaster AC Daikin serta Dimmer PWM LED 2-Zona).

Berdasarkan audit konsumsi daya listrik harian gedung, beban energi terbesar didominasi oleh dua subsistem:

  • Sistem Tata Udara (HVAC AC Split Inverter 1.5 PK / 1.55 kW rated): Mengonsumsi 65% – 70% dari total daya gedung.
  • Sistem Penerangan Interior (4 Fixture LED @ 70W = 280W total): Mengonsumsi 10% – 15% dari total daya gedung.
⚠️ Karakteristik Masalah: Pertentangan (Trade-Off) Objektif
Menaikkan setpoint suhu AC atau mematikan blower akan memangkas daya listrik secara signifikan, namun meningkatkan ketidakpuasan termal penghuni (PPD ISO 7730). Sebaliknya, meredupkan lampu menghemat daya penerangan, namun jika intensitas cahaya jatuh di bawah standar SNI 03-6197 (480 Lux), performa visual dan produktivitas kerja akan menurun.

Oleh karena itu, penyelesaian optimal tidak dapat dilakukan menggunakan optimasi kriteria tunggal (single-objective), melainkan membutuhkan pendekatan Multi-Objective Optimization Problem (MOOP) untuk menghasilkan sekumpulan solusi kompromi non-kalah (Pareto Optimal Front).

2. Formulasi Matematis Masalah Optimasi

2.1 Vektor Variabel Keputusan (Decision Space)

Setiap kandidat solusi direpresentasikan oleh vektor 4 dimensi:

X = [ Tset, PWMZ1, PWMZ2, FanSpeed ]T
Simbol Variabel Tipe Batas Domain Satuan Deskripsi Fisik
x1 Tset Kontinu [20.0 , 28.0] °C Setpoint suhu termostat AC inverter
x2 PWMZ1 Kontinu [0 , 100] % Duty cycle dimmer LED Zona 1 (Dekat Jendela)
x3 PWMZ2 Kontinu [0 , 100] % Duty cycle dimmer LED Zona 2 (Area Dalam)
x4 Fan Diskrit {1, 2, 3} Index 1: Low (0.15 m/s), 2: Med (0.25 m/s), 3: High (0.40 m/s)

2.2 Fungsi Objektif 1: Minimasi Daya Listrik Total (f1)

min f1(X) = PAC(Tset, Toutdoor, Fan) + PLamp(PWMZ1, PWMZ2)    [kW]

1. Model Empiris Daya Kompresor AC (PAC):

PAC = Prated × [1 - 0.06 · (Tset - 24.0)] × [1 + 0.03 · max(0, Toutdoor - 30.0)] × [1 + (Fan - 2) · 0.015]
Prated = 1.55 kW. Setiap kenaikan setpoint 1°C di atas 24°C menghemat ~6% daya. Suhu luar > 30°C menambah beban ~3%/°C.

2. Model Daya Lampu LED (PLamp):

PLamp = (1 / 1000) × [ (280 / 2) · (PWMZ1 / 100) + (280 / 2) · (PWMZ2 / 100) ]    [kW]

2.3 Fungsi Objektif 2: Minimasi Ketidaknyamanan Termal & Visual (f2)

min f2(X) = PPD(PMV) + Plux    [%]
Kedua komponen dinyatakan dalam satuan persen (%) sehingga memiliki skala sebanding dan tidak saling mendominasi secara artifisial.

1. Model Suhu Ruang Steady-State (Tindoor):

Tindoor = Tset + [0.3 + 0.02 · max(0, Toutdoor - 28.0)] × [1 - (Fan - 1) · 0.15]    [°C]
💡 Catatan Validasi Model AC:
Suhu ruangan dipengaruhi oleh beban panas internal (okupansi manusia, komputer, radiasi matahari), kelembapan, dan dinamika AC inverter aktual. Kalibrasi koefisien empiris menggunakan data sensor SHT31 dan PZEM-004T sangat dianjurkan.

2. Model Fanger PMV & PPD (ISO 7730 Terkalibrasi):

pa = (RHindoor / 100) · exp( 16.6536 - 4030.183 / [Tindoor + 235.0] )    [kPa]
Tneutral = 24.5 - 0.15 · (pa - 1.50) - 1.5 · (va - 0.15)    [°C]
PMV = max(-3.0, min(3.0, 0.32 · [Tindoor - Tneutral]))
PPD = 100.0 - 95.0 · exp(-0.03353 · PMV4 - 0.2179 · PMV2)    [%]
Tekanan uap pa secara konsisten bernilai kPa tanpa faktor pengali 10. Kondisi kantor: M = 1.1 met, Icl = 0.5 clo, va = {0.15, 0.25, 0.40} m/s.
💡 Catatan Validasi & Keterbatasan Model PMV (Poin A):
1. Persamaan tekanan uap jenuh air pa di atas konsisten dalam satuan kPa.
2. Model PMV dalam mesin optimasi ini merupakan model regresi linier surrogate terkalibrasi khusus untuk kondisi kantor tropis UNS guna menghasilkan komputasi instan (<1 µs) pada loop evolusioner. Model ini menyederhanakan Tradiant ≈ Tindoor dan tidak menjalankan iterasi implisit penuh neraca panas Fanger ISO 7730 (6 parameter dengan suhu permukaan pakaian tcl).
3. Untuk pengujian kepatuhan standar formal dan riset lanjutan, implementasi penuh ISO 7730 (misal paket pythermalcomfort) disarankan sebagai kontrol validasi.

3. Model Iluminansi Meja Kerja (Edesk):

Edesk = (Luxoutdoor × 0.08) + (280 · PWMZ1 / 100) + (180 · PWMZ2 / 100)    [Lux]
💡 Catatan Validasi Model Pencahayaan:
Koefisien iluminansi (0.08, 280, 180) harus dikalibrasi dengan pengukuran lux-meter aktual di meja kerja (ketinggian 0.8 m). Nilai PWM algoritma (0–100%) dikonversi ke mikrokontroler (0–255) via: PWM255 = round(2.55 × PWM%).

4. Fungsi Penalti Iluminansi Berbasis Persen (Plux) (Poin B):

Target SNI 03-6197 = 480 Lux dengan toleransi dead-band ±50 Lux → Zona bebas penalti [430, 530] Lux:
Plux =
• min( [ (430 - Edesk)/430 × 100 ] + δhard , 95 ) %    jika Edesk < 430 Lux
• 0 %    jika 430 ≤ Edesk ≤ 530 Lux
• min( [ (Edesk - 530)/530 × 50 ] , 30 ) %    jika Edesk > 530 Lux
Di mana δhard = whard · [ max(0, 350 - Edesk) / 350 ] × 100 % (dengan whard = 0.5) adalah denda keras tanpa dimensi campuran yang dinormalisasi dalam persen (%) terhadap ambang mutlak 350 Lux. Seluruh komponen bersatuan persen (%) dan pembatasan batas atas (cap 95%) diterapkan di akhir setelah penjumlahan.

3. Algoritma MOGA (NSGA-II)

Non-dominated Sorting Genetic Algorithm II (NSGA-II) adalah algoritma genetika multi-objektif elitist yang mengelompokkan individu ke dalam rank dominasi:

1. Fast Non-Dominated Sorting

Solusi p mendominasi q (p ≺ q) jika tidak ada objektif p yang lebih buruk dari q dan minimal satu objektif p lebih baik. Kompleksitas O(M·N²).

2. Crowding Distance (Idist)

Menghitung jarak kerapatan lokal antar solusi bertetangga. Solusi di area renggang diberi skor tinggi untuk menjaga persebaran front yang merata tanpa sharing parameter.

3. Crossover SBX & Mutasi Polinomial

Simulated Binary Crossover (pc = 0.85, ηc = 15) dan Mutasi Polinomial (pm = 0.08, ηm = 20) untuk rekombinasi kromosom bernilai riil secara adaptif.

4. Elitisme Strict (2N → N)

Populasi orang tua Pt dan anak Qt digabung (2N), lalu disaring N individu terbaik. Menjamin solusi non-kalah terbaik tidak pernah hilang.

4. Algoritma MOPSO (Particle Swarm Optimization)

Multi-Objective Particle Swarm Optimization (MOPSO) menirukan pergerakan kawanan partikel yang dibimbing oleh pengalaman personal terbaik (pbest) dan memori kolektif pada Arsip Pareto Eksternal:

vi,d(t+1) = clip( w · vi,d(t) + c1 r1 · (pbesti,d - xi,d(t)) + c2 r2 · (gbestd - xi,d(t)),   -vmax,d,   vmax,d )
xi,d(t+1) = xi,d(t) + vi,d(t+1)
w = 0.72 (inersia), c1 = 1.49 (kognitif), c2 = 1.49 (sosial), r1, r2 ~ U(0,1). Batas kecepatan vmax,d = 0.2 × (xmax,d - xmin,d).
1. Arsip Eksternal & CD Pruning

Menampung hingga 50 solusi non-terdominasi. Saat arsip penuh, pemangkasan dilakukan berdasarkan Crowding Distance terkecil (menghapus solusi di area terpadat).

2. Leader Selection (Roulette Wheel CD)

Leader (gbest) dipilih secara probabilistik dari arsip dengan bobot sebanding dengan CD-nya. Solusi di area jarang diprioritaskan agar sebaran front merata.

3. Pembaruan pbest Deterministik

Update jika xt+1 mendominasi pbest. Jika keduanya non-terdominasi, update dengan probabilitas 0.5. Jika pbest mendominasi, posisi pbest dipertahankan.

4. Variabel Diskrit Fan Speed

Kecepatan partikel dihitung kontinu, posisi diklem ke batas domain [1, 3], kemudian dibulatkan (rounded) ke bilangan bulat valid {1, 2, 3}.

Fitur Algoritma MOGA (NSGA-II) MOPSO (Particle Swarm)
Filosofi Dasar Evolusi biologi & seleksi alam Kecerdasan sosial kawanan (flocking behavior)
Mekanisme Memori Elitisme populasi gabungan (Pt ∪ Qt) Arsip Pareto eksternal terpisah (kapasitas 50) dengan CD pruning
Kekuatan Utama Eksplorasi global luas, tangguh optimum lokal Konvergensi sangat cepat, efisiensi komputasi tinggi

5. Fitur Seleksi Metode Per Subsistem (Dekomposisi Hybrid)

Sistem menyediakan fleksibilitas penuh untuk memilih algoritma optimasi yang berbeda pada masing-masing subsistem melalui 4 preset mode:

Preset Mode Metode AC Metode Lampu Mekanisme Kerja Komputasi
🧬 all_moga MOGA (NSGA-II) MOGA (NSGA-II) Evaluasi simultan 4 gen kromosom dalam 1 populasi genetika.
🐦 all_mopso MOPSO (Swarm) MOPSO (Swarm) Pencarian 4 dimensi posisi partikel dibimbing arsip Pareto eksternal.
🔀 ac_moga_lamp_mopso MOGA (NSGA-II) MOPSO (Swarm) Dua Fase: MOGA cari optimum AC → MOPSO cari optimum lampu.
🔄 ac_mopso_lamp_moga MOPSO (Swarm) MOGA (NSGA-II) Dua Fase Terbalik: MOPSO cari optimum AC → MOGA cari optimum lampu.

5.1 Landasan Ilmiah & Prosedur Re-evaluasi Dua Fase (Poin D)

Secara fisik, AC dan Lampu memiliki dinamika sistem yang berbeda: AC berinersia termal tinggi (respon menit hingga jam), sedangkan Lampu berespon fotometrik seketika (< 1 detik).

Prosedur Re-evaluasi Global Pasca-Dekomposisi: Untuk mencegah interaksi antar subsistem menyebabkan solusi akhir terdegradasi, seluruh solusi gabungan [Tset*, PWMZ1*, PWMZ2*, Fan*] dievaluasi kembali secara utuh menggunakan fungsi objektif global lengkap: f1 = PAC + PLamp dan f2 = PPD + Plux, lalu disaring melalui filter non-dominasi ketat.

📌 Catatan Benchmark & Keterbatasan Klaim (Poin D):
Klaim estimasi penghematan daya (~24.8%), penurunan waktu komputasi (~60%), nilai Hypervolume (0.935–0.942), dan waktu komputasi (< 200 ms) merupakan target desain dan hasil estimasi awal simulasi (preliminary benchmark) yang wajib diverifikasi melalui pengujian empiris sensorik berkala di BEMS Living Lab.

6. Analisis Kualitas Pareto & Ekstraksi Solusi

6.1 Deteksi Knee-Point Trade-Off (Garis Penghubung Titik Ekstrem) (Poin C)

Knee-point merepresentasikan titik pada kurva Pareto dengan perubahan marginal rate of substitution (MRS) paling tajam. Titik ini dihitung menggunakan jarak tegak lurus bertanda (signed perpendicular distance) terhadap garis chord yang menghubungkan titik-titik ekstrem aktual Pareto front:

dchord(P) = [ dx · (py,A - py) - dy · (px,A - px) ] / √(dx² + dy²)
A = (px,A, py,A) adalah titik ekstrem min f1; B = (px,B, py,B) adalah titik ekstrem min f2; dx = px,B - px,A; dy = py,B - py,A. Defleksi positif ke arah titik ideal (0,0) menunjukkan kelengkungan konveks terbaik.

8. Panduan Pengoperasian (User Manual)

8.1 Melalui Web Dashboard BEMS

  1. Buka alamat web http://10.8.0.7:3001/moga.html atau mopso.html.
  2. Pada panel bagian atas, pilih tombol preset (misal 🔀 AC: MOGA · Lamp: MOPSO) atau pilih manual melalui dropdown Metode AC dan Metode Lampu.
  3. Sistem secara otomatis menghitung kurva Pareto baru dan memperbarui grafik scatter Pareto front serta 5 kartu metrik eksekutif secara instan.
  4. Pilih salah satu titik solusi (Solusi A, Solusi B, atau Solusi C).
  5. Tekan tombol hijau Deploy Solution to Living Lab untuk mengirim setpoint suhu dan PWM lampu ke mikrokontroler fisik di ruangan.

8.2 Melalui Baris Perintah (CLI Python)

# Menjalankan optimasi hybrid via terminal server python optimizer.py --mode ac_moga_lamp_mopso --tout 33.0 --pop 50 --gen 60 # Menghasilkan luaran JSON untuk integrasi otomasi python optimizer.py --ac moga --lamp mopso --json > pareto_output.json
