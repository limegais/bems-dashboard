Smart Room Camera Configuration (Raspberry Pi)

Guide & configuration for MJPEG live camera stream endpoint.

How to Stream Camera Feeds from Raspberry Pi:
  1. Jalankan Smart Room di Raspi: Masuk ke folder dashboard lalu jalankan server:
    cd ~/smartroom/dashboard && python3 app.py
  2. Cari IP Raspberry Pi: Buka terminal Raspi dan ketik:
    hostname -I (misal: 192.168.1.50 atau 10.18.13.xxx).
  3. Same Wi-Fi/LAN Network: Ensure this host and the Raspberry Pi are on the same local subnet or Tailscale.
  4. Enter URL: Input http://<IP_RASPI>:5000/video_feed in the field below. pada kotak di bawah lalu klik Save & Apply.
Port Default: 5000
Preset Cepat:
Belum dilakukan pengecekan. Klik tombol "Uji Koneksi (Ping)" di bawah untuk mengetes keterjangkauan server Raspberry Pi.
